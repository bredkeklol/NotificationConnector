# Notification Connector

A protocol-independent notification connector developed as part of an internship project.

## 🚀 Overview

This project simulates a notification system where notifications are generated by a simulator, stored by a .NET backend API, and displayed on a React dashboard.

The project is designed to be extended with multiple communication protocols such as:

- RabbitMQ
- Redis
- WebSocket
- Webhook
